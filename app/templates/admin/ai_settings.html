پرامپت‌های سفارشی (اختیاری)

اختیاری — قالب JSON سفارشی برای کنترل دقیق‌تر پرامپت‌ها. در صورت خالی بودن از پرامپت‌های پیش‌فرض استفاده می‌شود.

راهنما

  • برای استفاده از OpenAI، کلید API خود را وارد کنید (پیش‌فرض: api.openai.com)
  • برای سرویس‌های سازگار با OpenAI (مثل Together AI، Groq، و غیره)، پرووایدر را «سفارشی» انتخاب و آدرس API را وارد کنید
  • مدل‌های پیشنهادی متن: gpt-4o، gpt-4o-mini، claude-3-sonnet، llama-3-70b
  • مدل‌های پیشنهادی تصویر: dall-e-3، flux-schnell، stable-diffusion-xl
  • پس از ذخیره، فرآیندهای جدید از تنظیمات جدید استفاده خواهند کرد
